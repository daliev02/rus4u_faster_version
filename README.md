# RUS4U — optimized website

Extract the ZIP and open index.html. No installation or build step is required.
To upload, use index.html, app.js, style.css and the complete assets folder together.

Changes:
- Responsive WebP images and smaller image variants; transparent backgrounds retained.
- Images below the hero load lazily; hero has high fetch priority.
- Top Telegram banner: https://t.me/rus4u_global
- Approved introductory paragraph, with Uzbek and Russian translations.
- English: international prices only ($119 group / $399 individual).
- Uzbek: Uzbekistan prices only ($36.99 group / $200 individual).
- Russian: both pricing options via the existing selector.
- Each package includes 12 classes.

Checked in Chromium at 320, 375, 768, 1024 and 1366-pixel iframe widths in all three languages; no horizontal page overflow. This is responsive browser testing, not physical-device testing or a measured mobile-network load-time guarantee.

Original image assets: 23,914,193 bytes. Optimized variants combined: 1,107,242 bytes (about 95% smaller). Each visitor downloads only the selected responsive variants and course images they view.

Registration and placement-test buttons retain the existing manager fallback because a registration form and direct test-file link were not supplied. The new top banner opens the main Telegram channel for free learning materials and videos.

This ZIP has not been uploaded to GitHub or deployed to the live site.
